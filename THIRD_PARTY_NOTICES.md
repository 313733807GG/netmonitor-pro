Texts supplied with this release are in THIRD_PARTY_LICENSES and component source headers. The portable distribution uses dynamically loaded, replaceable Qt/PySide6 libraries under `_internal` (including any component subdirectories).

PySide6 wheel metadata declares an open-source licensing option even where its wheel includes a commercial license reference text. The release includes LGPL/GPL license texts and retains that reference rather than interpreting it as a commercial grant. Qt's included third-party notices and license texts are retained separately. No commercial Qt license is granted by this project.

Users may replace the dynamically linked LGPL libraries with compatible modified versions, subject to their own licenses and ABI requirements. Reverse engineering for debugging such library modifications is not prohibited by this project. The public source, requirements and build specification support rebuilding the application with compatible libraries; the `_internal` directory must remain intact. NetMonitor does not add a cryptographic lock to those libraries. Windows application control may independently govern which binaries run.

Corresponding unmodified upstream sources are available from the exact-version upstream repositories above; Qt sources are also published at https://download.qt.io/official_releases/qt/6.11/6.11.2/submodules/ and Python bindings at https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.11.2-src/ . If a link changes or a required source/notice is missing, contact the maintainer through this repository. Do not assume this document replaces each component's full license.

The bundled pywintrace sources match the maintained local package; generated bytecode and package caches are excluded.
