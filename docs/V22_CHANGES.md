# v22.0.1 当前行为与维护重点

本文件补充安装、使用、AI安装和维护指南；旧文档中只描述两来源或仅Verge的段落，以本文件和FlClash指南为准。

## 安装及兼容范围

Windows x64，正式便携包包含EXE和完整_internal，无需另装Python。源码运行/构建仍需独立Python3.12及requirements.txt，测试入口为python -I tools/project_cli.py test。
已在Clash Verge Rev/Mihomo v1.19.32及FlClash0.9.2/Mihomo v1.19.33实测。其他Mihomo可能适用，非Mihomo不建议下载使用。程序未做发布者代码签名；安全系统可能拦截新EXE或依赖，不能保证所有机器放行，遇拦截保留证据，不关闭安全策略或靠换哈希碰运气。

## 评分与风险明细

显示IPPure、CleanIP及可用的FlClash同IP缓存。自动评分按本次启动的客户端/订阅/AI节点缓存一次，手动IP质量可刷新；探测周期只影响ChatGPT连通性/HTTP延迟，新增1分钟选项，不控制IP评分周期。

CleanIP CLI确认IP后，经同一专用出口读取其公开IP报告中的命中标签。有命中直接显示名称；汇总与明细不同则优先明确命中，悬停保留双方、来源及数据时间。无命中显示未检出；不增加“部分未完成”字样，因此此文案不代表全部数据源均有效。明细不可用时保留汇总并在悬停说明，未知/缺失不伪造成命中或安全保证。

不执行DNS/WebRTC泄漏检测；DNSBL黑名单属于信誉项目，正常读取。网页结构/接口可能变化，需维护src/cleanip_details.py的页面样例回归。固定每节点缓存遇动态出口变化时应手动刷新；各站IP不一致不能拼成同一结果。

## 界面与吸附

亮蓝/青色图标，奶黄色节点名，严格路由开蓝/关粉，Fl与IPPure同行并和风险列对齐。实心IP类型图标、细边框、增强呼吸灯。窗口内距屏幕边缘4逻辑像素时触发吸附，贴边和越界也可触发；外侧留白保持8。修复副屏底边缩小后跳边，悬停展开/收回保留原屏幕和边。

规则命中是当前内核连接快照中匹配规则的数量，前5类，不是访问次数或流量。Match通常为兜底（内核未提供规则名也会回退该名），GeoIP/cn为中国IP，DomainSuffix为域名后缀；最终出口看规则动作和连接右列。

## 数据与未知名称维护

原LocalAppData/NetMonitorPro数据及QSettings标识保留。升级前正常退出并备份账本完整目录（含WAL/SHM）、logs和HKCU/Software/NetMonitorPro设置。节点特征/账本是本地文件，不因保存数据而占用网络端口；检测及控制接口请求会建立正常网络连接。

未知清单按域名/其他500、裸IP500、异常200独立配额，记录数/出现次数是轮询观察值。别名库仍需使用者核实并维护；动态/共享IP只能保留有时间范围的域名候选，不能仅凭运营商、程序或时间接近永久归属某个应用。历史因配额淘汰的内容不能凭空恢复。不要公开原日志、账本、节点/订阅或未遮挡截图。

## AI自动安装与后期维护

给AI提供本仓库地址，让它先读AI_INSTALL、INSTALLATION、USAGE、CLASH_VERGE_SETUP或FLCLASH_SETUP、MAINTENANCE及本文件。先核对平台/现有数据/运行版本，校验Release哈希，准备可回退安装；配置代理扩展前合并原规则并协调重载时间。替换NetMonitor前请求退出，验收实际EXE版本、ETW、API、IP检测组REJECT及旧账本继续写入。不得把演示分数当作本机验收结果。

源码修改后运行192项回归及对应UI/网络mock验证；测试使用隔离数据和capture=False，不启动第二个ETW采集。尤其防止UAC启动丢失测试环境变量而写入正式账本。出错先保存脱敏证据，修复后再发布新版本。
