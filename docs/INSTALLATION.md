# 安装、默认设置、升级与卸载

## 下载哪个包

使用对应正式Release的Windows x64完整程序ZIP，连同`release-manifest.json`和`SHA256SUMS.txt`校验。源码ZIP与GitHub自动生成的Source code不是双击可用程序。便携包不需要Python、Node或浏览器驱动。

Windows文件版本、EXE哈希、ZIP哈希从同一Release清单核对，不使用旧截图或其他版本的固定哈希。程序没有签名时必须如实告知；哈希校验不等于获得Windows信任。

## 默认安装位置

默认安装在可写的非系统固定盘：优先既有合规安装位置，其次合适的D盘，再选择其他非系统盘，通常为`<盘符>:\Apps\NetMonitor`。系统盘通过实际Windows卷判定，不假定一定是C。

无非系统盘时只需向用户说明并请其指定可用位置，不静默退回系统盘，不自动分区。程序文件在非系统盘，用户数据仍按兼容约定保存在用户配置目录；**非系统盘安装不意味着系统盘完全零数据写入**。不要为此擅自迁移数据或注册表。

完整解压后应有EXE、整个`_internal`、文档、示例与许可。创建快捷方式时使用真实EXE，工作目录设为其所在目录；不创建开机启动或计划任务。

## 首次默认：关闭入账和自启动

程序本身必须在没有保存设置时默认暂停入账；AI安装还应在首次启动前校验设置。当前约定：

| 项目 | 位置/含义 |
|---|---|
| QSettings | organization/application均为`NetMonitorPro` |
| 入账暂停键 | `HKCU\Software\NetMonitorPro\NetMonitorPro`中的`history_paused`；true表示关闭入账 |
| 标准自启项 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`下的`NetMonitorPro`值 |
| 日志/账本根 | `%LOCALAPPDATA%\NetMonitorPro` |

随包[初始化助手](../tools/Initialize-NetMonitorDefaults.ps1)只在软件已退出且目标EXE已经安装时使用。默认关闭入账和本软件标准HKCU自启项；升级时只在确实存在用户明确选择的旧入账设置时使用`-PreserveExistingHistory`。

```powershell
# 路径仅为示例，替换成前面选定的实际非系统盘安装位置。
& 'D:\Apps\NetMonitor\tools\Initialize-NetMonitorDefaults.ps1' -InstallDir 'D:\Apps\NetMonitor'
```

不要改变系统执行策略来运行此脚本；若组织或安全策略阻止，应报告具体原因并按管理员认可的方式处理，不绕过限制。不能让用户下载脚本后未经核对直接远程执行。

以实际运行NetMonitor的Windows账户设置HKCU。如果UAC需要输入另一个管理员账户凭据，应核对目标用户，避免写到另一个账户后宣称默认已生效。

自启动关闭不询问是否开启；入账关闭后只解释用途，不主动诱导用户开启。运行中修改注册表可能被退出保存覆盖，必须先退出。

## 代理关联

安装AI应完成[两款代理配置](PROXY_SETUP.md)，保持用户原有节点和规则。NetMonitor的检测端口、普通代理端口和控制API是三个不同用途。只配好普通代理不能自动满足IP质量检测要求。

安装结束应区分：软件启动/采集正常、控制接口正常、当前订阅检测入口正常、第三方报告是否成功。网站429/安全验证是第三方限制，不能以换出口、关闭证书验证或后台拉起浏览器绕过。

## 升级与回退

1. 找到旧实例和真实安装路径，协调退出；备份完整旧安装、原数据目录和本软件注册表。运行中备份SQLite使用一致性备份；退出后完整复制含WAL的目录。
2. 校验新资产，解压新暂存目录后替换完整发行目录；不要只换EXE，不混用不同版本运行库。
3. 保留已明确保存的入账选择及旧历史。无保存选择按首次默认关闭。按安装政策关闭NetMonitor自启动，不影响代理软件自启动。
4. 旧安装在系统盘时，迁移程序与快捷方式到非系统盘；日志/账本/设置不跟随程序目录迁移。
5. 启动后验证版本、路径、实时连接、入账状态、现有历史可读及代理关联。暂停时验收不新增样本；用户原本选择入账开启时才核对继续写入。
6. 回退只恢复完整旧程序，不默认覆盖已增长的用户数据库。若旧版恢复后台浏览器或不同默认行为，必须明确说明兼容风险，不能悄悄改变用户已经拒绝的功能。

## 卸载

关闭本软件自启并从托盘退出，移除明确归属的程序目录和快捷方式。默认保留用户数据；永久删除日志/账本/设置须用户另行选择。

解除代理关联时只移除自己添加的NetMonitor函数、调用、监听器/组或订阅绑定，保留后续个人改动。不要用旧整份配置或旧数据库覆盖当前内容。安排合适时机应用修改。

## 默认关闭后的验收解释

账本文件可能被创建且含空表，日志也可能更新，这不等于已记录流量。检查`history_paused`及真实流量表的样本/流量变化；不要要求文件完全不变。重启后仍应保持用户的开关选择。
